## 1. 가장 빠른 방법

**필요한 것: Roblox Studio 하나뿐이다.** 터미널도, Rojo 도, Wally 도 필요 없다.

### 1-1. Roblox Studio 설치

https://create.roblox.com/ 에 로블록스 계정으로 로그인하고 **Start Creating** 을
누르면 Studio 설치 파일을 받을 수 있다. (Windows / macOS 만 가능하다.
리눅스나 크롬북에서는 Studio 가 돌아가지 않는다.)

### 1-2. 플레이스 파일 받기

저장소에 **`ForgeFever.rbxlx`** 파일이 들어 있다. 이 안에 게임 전체가 담겨 있다.

GitHub 웹에서 받는 법:

1. 저장소의 `claude/awesome-mccarthy-iavp1p` 브랜치를 연다
2. `ForgeFever.rbxlx` 를 클릭한다
3. 오른쪽 위 **Download raw file** (아래 화살표 아이콘) 을 누른다

### 1-3. 열고 실행하기

1. 받은 `ForgeFever.rbxlx` 를 **더블클릭**한다 → Roblox Studio 가 열린다
   (안 열리면 Studio 를 먼저 켜고 `File > Open from File` 로 연다)
2. 상단 **Home** 탭의 **Play** 버튼(▶)을 누른다
3. 화면에 대장간 UI 가 뜨고 강화 버튼이 보이면 성공이다

> **Play 를 눌렀는데 아무것도 안 보인다면** 화면 아래쪽 **Output** 창을 봐라.
> (안 보이면 상단 `View` 탭 → `Output`) 빨간 글씨가 있으면 그 내용을 알려 줘.

**정상일 때 Output 에 찍히는 것:**

```
[DataService] 스토어 "ForgeFever_DEV" 사용
[Bootstrap] 서비스 11개 시작 완료
[ChatCommandService] 명령어 6개 등록
```

강화 버튼을 누를 때마다 이런 줄이 추가된다:

```
[Economy] 12345 gold sink -10 (enhance_cost) → 90
[Enhance] 12345 +0 → success (비용 10)
```

## 2. 혼자서 확인할 것

Play 상태에서 하나씩 해 보면 된다.

| 확인할 것 | 방법 | 기대 결과 |
| --- | --- | --- |
| 강화 | 아래 큰 버튼을 누른다 | 레벨이 오르거나 그대로거나 깨진다. 오른쪽 피드에 모루 영감의 대사가 뜬다 |
| 연타 방지 | 버튼을 빠르게 여러 번 누른다 | 요청 중에는 버튼이 회색으로 잠긴다 |
| 확률표 | "확률표" 버튼 | 0~20강 전 구간 표가 뜨고, 지금 레벨 줄이 주황색으로 강조된다 |
| 파괴 연출 | 10강 이상에서 계속 강화 | 붉은 섬광 + 조각이 흩어지고 파편이 들어온다 |
| 파편 교환 | 파편 50개 이상일 때 상단 "방지권" 표시를 누른다 | 확인 창 → 방지권 +1 |
| 방지권 | "방지권 사용" 을 켜고 파괴 확률 구간에서 강화 | 파괴가 나와도 레벨이 유지되고 방지권이 1개 줄어든다 |
| 판매 | "판매" 버튼 | 확인 창 → 골드를 받고 레벨 0 으로 |
| 이름 짓기 | 무기 이름(레벨 위 글씨)을 누른다 | 입력 창 → 이름이 바뀐다 |
| 기록 | "기록" 버튼 | 도감 / 업적 / 랭킹 / 설정 탭 |
| 언어 | 기록 → 설정 → "언어: 한국어" | 영어로 바뀐다. 다시 누르면 한국어 |
| 채팅 명령어 | 채팅창에 `/강화` 입력 | 버튼과 똑같이 동작하고 결과가 채팅에 뜬다 |
| 튜토리얼 | 처음 3번 강화 | 버튼 위에 모루 영감의 안내가 뜨고 3번 뒤 사라진다 |

**랭킹은 비어 있는 게 정상이다.** 랭킹은 실제로 게임을 공개해서 DataStore 가
동작할 때부터 쌓인다 (아래 4번 참고).

## 3. 2명으로 배틀 테스트하기

배틀은 상대가 있어야 하므로 클라이언트를 2개 띄운다.

1. 상단 **Test** 탭을 누른다
2. **Clients and Servers** 묶음에서
   - **Players** 를 **2** 로
   - 모드를 **Local Server** 로
3. **Start** 를 누른다 → 창이 3개 열린다 (서버 1 + 플레이어 2)
4. 플레이어 창 하나에서 **"배틀"** 버튼을 누르고 상대를 고른다
5. 다른 플레이어 창에 도전장 팝업이 뜬다 → **"받는다"**
6. 양쪽에 결과 창이 뜬다

확인할 것:

- 15초 동안 아무것도 안 누르면 자동으로 거절된다
- **배틀 뒤에도 양쪽 무기 레벨이 그대로다** (배틀은 레벨을 건드리지 않는다)
- 한쪽이 15강 이상을 성공하면 다른 쪽 채팅창에도 알림이 뜬다
- 한쪽에서 강화해도 다른 쪽 골드는 변하지 않는다

끝낼 때는 **Test 탭 → Cleanup** 을 누른다.

## 4. 데이터 저장을 진짜로 테스트하기

**1번 방법(파일 더블클릭)으로 연 게임은 데이터가 저장되지 않는다.** Studio 를
끄면 골드와 레벨이 초기화된다. 정상이다 — 로블록스는 "아직 공개되지 않은
플레이스"에 데이터 저장을 허용하지 않는다.

진짜 저장을 확인하려면:

1. Studio 에서 **File → Publish to Roblox As...** 로 게임을 한 번 올린다
   (비공개로 올려도 된다. 공개할 필요 없다)
2. Studio 상단 **Home → Game Settings → Security** 로 간다
3. **Enable Studio Access to API Services** 를 **켠다**
4. **Save** 를 누른다
5. 다시 Play 해서 골드를 쓰고, Studio 를 완전히 껐다가 다시 열어 Play 한다
6. 골드와 레벨이 그대로 남아 있으면 성공이다

> Studio 에서 테스트하는 데이터는 `ForgeFever_DEV` 라는 별도 저장소에 들어간다.
> 실제 공개된 게임은 `ForgeFever_PROD` 를 쓴다. **둘은 절대 섞이지 않는다.**
> 그래서 Studio 에서 아무리 골드를 넣고 테스트해도 실제 유저 데이터는 안전하다.

### 서버 강제 종료 후에도 데이터가 남는지

ProfileStore 가 서버 종료 시 모든 데이터 저장이 끝날 때까지 기다리도록 되어 있다.
Test 탭에서 **Local Server** 로 실행한 뒤 **Cleanup** 으로 강제 종료하고,
다시 Play 해서 데이터가 남아 있는지 확인하면 된다.

## 5. 코드를 고치면서 개발하려면

1번 방법의 플레이스 파일은 **특정 시점의 사진** 이다. 코드를 고쳐도 그 파일은
바뀌지 않는다. 계속 개발하려면 파일과 Studio 를 실시간으로 연결하는
**Rojo** 를 쓴다.

### 5-1. 툴 설치

터미널(Windows 는 PowerShell, Mac 은 터미널)에서 [Rokit](https://github.com/rojo-rbx/rokit)
을 설치한 뒤, 저장소 폴더에서:

```bash
rokit install
```

`rokit.toml` 에 적힌 rojo / selene / stylua / lune 가 한 번에 설치된다.

> 버전 오류가 나면 버전 없이 다시 고정하면 된다:
> `rokit add rojo-rbx/rojo` `rokit add JohnnyMorganz/StyLua` 등

### 5-2. Studio 플러그인 설치

```bash
rojo plugin install
```

### 5-3. 연결

```bash
rojo serve
```

Studio 에서 새 Baseplate 를 만들고, **Plugins** 탭의 **Rojo** 창에서
**Connect** 를 누른다. (기본 주소 `localhost:34872`)

연결되면 `src/` 의 파일들이 Studio 안으로 들어온다. 이제 파일을 저장할 때마다
Studio 에 즉시 반영된다.

> **Studio 안에서 스크립트를 직접 고치지 마라.** 다음 동기화 때 덮어써진다.
> 코드는 항상 파일에서 고친다.

### 5-4. 다시 플레이스 파일로 만들기

```bash
rojo build -o ForgeFever.rbxlx
```

### 5-5. 테스트와 검사

```bash
lune run tests/run                # 로직 테스트 73개
lune run tools/simulate_economy   # 경제 시뮬레이션
stylua src tests tools            # 코드 정렬
selene src tests tools            # 코드 검사
```

## 6. 게임을 공개하려면

`README.md` 의 **출시 전 체크리스트** 를 따르면 된다. 핵심만 적으면:

1. **File → Publish to Roblox** 로 게임을 올린다
2. **Game Settings → Security → Enable Studio Access to API Services** 를 켠다
3. `src/shared/Config/Game.luau` 의 `ADMIN_USER_IDS` 에 본인 UserId 를 넣는다
   (UserId 는 자기 로블록스 프로필 주소의 숫자다)
4. 게임패스와 개발자 상품을 만들고 `src/shared/Config/Products.luau` 에 ID 를 넣는다
   - **ID 를 안 넣어도 게임은 정상 동작한다.** 상점이 비어 있을 뿐이다
5. 아이콘·썸네일·설명을 등록한다 (전부 오리지널 에셋으로)
6. 친구 5명 이상과 비공개 테스트를 한다

## 7. 문제가 생겼을 때

먼저 **Output 창**(View 탭 → Output)을 확인한다. 아래는 나올 수 있는 메시지와 뜻이다.

### `ProfileStore 모듈을 찾을 수 없습니다`

Rojo 동기화가 덜 됐다. `src/server/vendor/ProfileStore.luau` 가 Studio 의
`ServerScriptService > Server > vendor` 아래에 들어와 있는지 확인한다.

### `TextChatService 가 아닌 레거시 채팅이 켜져 있어...`

채팅 명령어가 등록되지 않았다는 뜻이다. **Game Settings → Communication** 에서
채팅을 최신 방식(TextChatService)으로 바꾼다. 버튼은 전부 정상 동작하므로
급하지 않으면 넘어가도 된다.

### `관리자 UserId 가 비어 있어 관리자 명령을 등록하지 않았습니다`

정상이다. `Config/Game.luau` 의 `ADMIN_USER_IDS` 를 채우면 `/관리` 명령이 켜진다.
비워 두면 아무도 관리자 명령을 쓸 수 없다 — 안전한 기본값이다.

### `순위 저장소를 열지 못했습니다` / 랭킹이 비어 있다

DataStore 접근이 아직 허용되지 않았다. 위 4번을 따른다.
게임 진행에는 아무 영향이 없다.

### 데이터가 저장되지 않는다

위 4번을 따랐는지 확인한다. 공개되지 않은 플레이스에서는 저장이 안 되는 게 정상이다.

### 그 외

Output 창의 빨간 글씨를 **그대로 복사해서** 알려 주면 된다. 어느 줄에서 났는지까지
찍히므로 대부분 바로 고칠 수 있다.
