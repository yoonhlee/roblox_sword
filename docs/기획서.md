# 강화의 대장간 기획서

게임 기획의 기준 문서. 새 아이디어는 아래 6절의 절차를 거쳐 이 문서에 들어온다.

상태 표시

| 표시 | 뜻 |
| --- | --- |
| ✅ 구현됨 | 코드에 들어가 있다 (Studio 실동작은 별도 확인 필요) |
| 📝 기획됨 | 승인됐지만 아직 구현 안 함 |
| ⚠️ 빈 곳 | 기획상 있어야 하는데 구현이 없거나, 기획 자체가 비어 있다 |

---

## 1. 한 줄 소개

무기를 골드로 두드려 강화하고(성공 / 유지 / 파괴), 같은 서버 사람과 겨뤄 골드를 버는
캐주얼 강화 게임. 대장간의 무뚝뚝한 노인 **모루 영감**이 결과를 한 줄씩 읊어 준다.

**핵심 경험**: 1~3분짜리 짧은 세션 · 버튼 한 번의 긴장감 · 친구와의 비교와 배틀 · 수집

**타깃**: 로블록스 모바일 유저 중심, 한국어 기본 + 영어

---

## 2. 핵심 루프

```
   골드 ──→ 강화 ──→ 성공: 레벨 +1 ──→ 더 높은 판매가 / 배틀 승률 / 도감·업적
    ↑         │
    │         ├──→ 유지: 그대로 (다시 시도)
    │         │
    │         └──→ 파괴: 레벨 0 + 파편 ──→ 파편 50개 = 방지권 1개 ──→ 다음 고레벨 도전
    │
    └── 출석 · 15분 플레이 보상 · 배틀 · 판매 · 도감/업적 보상
```

15강까지는 운과 골드로, 16강부터는 **방지권을 쓰는 것이 정상 경로**다
(시뮬레이션 근거: `docs/economy.md`).

---

## 3. 시스템별 현재 기획

### 3-1. 강화 ✅

- 1회 = 해당 레벨 비용 차감 → 서버가 결과 결정. 최대 +20.
- 확률표: 0~9강은 파괴 없음, 10강부터 파괴 5% → 19강 25%.
  전체 표는 `src/shared/Config/EnhanceTable.luau` (원안: `docs/원본-지시서.md` 4절).
- 확률표는 언제나 화면에서 열람 가능.
- 15강 이상 성공 시 서버 전체 채팅 공지.

### 3-2. 파괴 · 파편 · 방지권 ✅

- 파괴 시 파편 `floor(레벨^1.5)` 개 (10강 31개, 19강 82개).
- 파편 50개 → 방지권 1개. 방지권은 골드로도 구매(2,500).
- 방지권 사용을 켜 두면 파괴가 유지로 바뀌고 1개 소모. 파괴가 실제로 나왔을 때만 소모.

### 3-3. 판매 ✅

- 현재 레벨의 판매가(0강 0 ~ 20강 25,000)를 받고 레벨 0 으로.
- 지어 준 이름은 유지된다.

### 3-4. 배틀 ✅

- 같은 서버 상대에게 도전 또는 아무나 매칭. 15초 무응답은 거절.
- 승률 `1 / (1 + 10^((상대Lv - 내Lv) / 4))`. 약자가 이기면 보상 최대 3배.
- 승자 `30 × (1 + 0.1 × 상대Lv) × 역전배율`, 패자 5골드. 레이팅 Elo(K=24).
- **배틀로 무기가 깨지거나 레벨이 내려가지 않는다.**
- 어뷰징 방지: 쿨다운 10초, 하루 보상 30회, 같은 상대 하루 3회, 계정 3일 미만 보상 50%.

### 3-5. 경제 ✅

| 획득 | 소비 |
| --- | --- |
| 출석 100~1,000 (연속 7일) | 강화 비용 |
| 15분마다 120 | 방지권 구매 2,500 |
| 배틀 | (무기 외형 변경 500 — ⚠️ 미구현) |
| 무기 판매 | |
| 도감 칸 150, 업적 100~20,000 | |

시뮬레이션 결과(헤비 유저 하루 약 3,900골드): 15강 약 1주, 20강은 방지권 사용 시 약 12주.

### 3-6. 도감 · 업적 · 랭킹 ✅

- 도감: 무기 5종 × 레벨 구간 4개(5/10/15/20) = 20칸, 칸마다 150골드.
- 업적 20개 (첫 망치질, 맨손으로 +15, 열 번 연속 제자리, 100승 등).
- 랭킹: 최고 강화 레벨, 배틀 레이팅 상위 50명.

### 3-7. 수익화 ✅

- 원칙: **확률 결과 자체를 Robux 로 팔지 않는다.** 확률표는 항상 공개.
- 게임패스: 골드 획득 +20% ✅ / 무기 외형 슬롯 확장 ⚠️ / VIP 채팅 태그 ⚠️
- 개발자 상품: 골드 5천·3만·10만, 방지권 5개 묶음.
- 상품 ID 를 넣기 전에는 상점이 비어 있다.

### 3-8. 라이브 운영 ✅

- 원격 설정으로 점검 모드, 공지, 확률 버프 이벤트(성공 +%p, 유지에서 차감, 파괴는 불변).
- 관리자 채팅 명령 `/관리` 와 감사 로그, 골드 급증 탐지.

### 3-9. 화면 · 연출 · 캐릭터 ✅

- 중앙 무기 레벨, 하단 큰 강화 버튼, 우측(모바일은 상단 접이식) 결과 피드.
- 연출: 성공 섬광 / 유지 흔들림 / 파괴 붉은 섬광+조각 / 20강 특수 연출.
- 모루 영감의 대사: 결과별 2~3종 무작위.
- 첫 접속 시 강화 3회 안내. 설정에서 소리·언어 전환. 무기 이름 짓기(필터링).

## 4. 알려진 빈 곳 ⚠️

기획 논의를 시작하기 전에 알아 둬야 할 것들이다.

| # | 빈 곳 | 영향 |
| --- | --- | --- |
| G1 | **무기 교체 기능이 없다.** 무기 5종과 해금 레벨(`unlockLevel`)은 정의돼 있지만 모두가 무쇠 검만 쓴다 | 도감 20칸 중 16칸이 달성 불가. 업적 "도감 10칸"도 달성 불가 |
| G2 | 무기 외형 변경 기능 없음 | 소비처 하나와 게임패스 "외형 슬롯 확장"이 의미가 없다 |
| G3 | VIP 채팅 태그 기능 없음 | 상품 ID 를 넣으면 **효과 없는 게임패스를 파는 상태**가 된다. 구현 전에는 ID 를 넣으면 안 된다 |
| G4 | 사운드 에셋 없음 | 게임이 무음이다 |
| G5 | 무기 외형(3D 모델·이미지) 없음 | 화면 중앙에 숫자와 이름만 있다 |
| G6 | 로비·월드 공간 없음 | 기본 Baseplate 위에서 UI 만 뜬다. 랭킹 보드도 화면 패널로만 있다 |

## 6. 제안 절차와 기록

1. 개발자가 아이디어를 제안한다.
2. Claude 가 **장점 · 단점 · 영향 범위 · 작업량 · 의견**을 정리한다.
3. 개발자가 승인하면 이 문서의 해당 절에 📝 로 추가하고 아래 표에 기록한다.
   보류·거절도 기록한다.
4. 구현은 개발자가 요청할 때 한다. 구현되면 📝 → ✅.
