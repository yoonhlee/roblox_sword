# 강화의 대장간 — 기획 현황 브리프

> 작성일 2026-11-14 · 대상: 이 프로젝트를 처음 보는 동료
> 상세 기준 문서는 `docs/기획서.md`. 이 문서는 **판단에 필요한 것만** 추린 요약이다.

---

## 30초 요약

- **무엇**: 로블록스 모바일 게임. 검을 골드로 강화하고, 그 검을 들고 **추격 생존
  경주**를 달려 골드를 번다. 결과는 오리지널 NPC "모루 영감"이 한 줄씩 읊어 준다.
- **어디까지 왔나**: 처음 지시서 기준 프로토타입(강화 + 1:1 배틀)은 **코드로 완성**돼 있다.
  그 뒤 기획을 크게 바꿨고(제안 38건 승인, 1건 취소, 1건 승인 후 삭제), **새 기획은 아직 코드에 반영하지 않았다.**
- **바뀐 핵심 세 가지**
  1. 게임 목표: 1:1 배틀 → **추격 생존 경주** (달린 거리만큼 골드)
  2. 강화: **2구간** — 1~10강 실패 없음, 11~20강 실패하면 10강으로 복귀
  3. 수익화: 골드를 Robux 와 완전히 분리, **방지권이 유일한 유료 상품**
- **지금 필요한 것**: 결정 대기 (아래 3절). **D22**(검 20종 확정)가 먼저고, 그다음 **D16**(수치)이다.

## 1. 게임 구조 (승인된 기획)

```
   골드 ──→ 강화 ──→ 더 강한 검 ──→ 추격 생존 경주 ──→ 레벨 비용 × 배율 × 달린 비율
             │          │               (착용 검의 레벨·특수 능력 + 도감 기념)
             │          └─ 검 여러 개: 소지 상한을 골드로 구매, 착용 검 선택
             ├─ 1구간 1~10강: 실패 없음
             └─ 2구간 11~20강: 실패하면 10강 복귀 → 파편 획득

   로비 트레드밀 ──→ 20초당 100골드 (기본 소득)
   파편 50개 ──→ 방지권 뽑기          방지권 ──→ 2구간 실패를 막아 줌
   Robux ──→ 방지권 상품 (유일한 유료 상품)
```

### 강화 (P1·P2·P5·P15·P17·P22·P24)

| | 1구간 (1~10강) | 2구간 (11~20강) |
|---|---|---|
| 성공 | 100 → 15%, 갈수록 크게 하강 (100·97·94·89·84·76·66·53·37·15) | 66 → 2%, 완만한 로그형 하강 (66·53·43·35·27·21·16·11·6·2) |
| 실패 | 0% | 5% → 20%. **실패하면 10강으로 복귀** |
| 유지 | 100 − 성공 | 100 − (성공 + 실패) |

- 강화 비용 = **100 × (1 + 2^레벨)** × (가진 검 수)^1.1. 0→1강 200, 9→10강 5만 1,300,
  19→20강 약 5,243만.
- 0강 → 20강 기대 시도 약 9천 4백 번. 대부분 마지막 19→20강(성공 2%)에서 나온다.
- **판매 기능은 삭제했다** (P41). 새 검은 뽑기, 골드는 경주·트레드밀이 맡는다.

### 추격 생존 경주 (P3·P18·P19·P23)

- 매칭을 누르면 **10초 안에** 출발. **레벨이 섞인 경주가 기본**이다(같은 서버 안).
  대기열이 20명(일단 정한 기준, P43)이 되면 즉시, 아니면 10초에 대기자 전원 출발.
- 모두가 공유하는 추격자 하나가 **지수적으로 빨라지며** 쫓아온다. 잡히면 탈락 → 관전 또는 바로 로비로.
- 방해 없이 쉬지 않고 달릴 때 잡히는 시간: **0~1강 20초 → 20강 90초.** 거리 차이는 약 11배.
- 보상 = **착용 검 레벨 비용 × 배율 × (달린 거리 ÷ 최대 거리)**, 탈락 순간 확정. + 1~3위 보너스.
  배율: 1구간 ×2 → ×5, 2구간 ×5 → ×10 (지수형, P28·P29). 레벨이 하나 오를 때마다 보상이 약 2~2.4배.
- 진행 속도 (평균 80% 거리 가정): 10강 약 6분, 15강 약 12분, 20강 약 9시간.
  20강까지 시간은 일부러 늘리지 않고, 오래 즐길 거리는 **새 검 강화**로 만든다 (P27).
- **11강부터 특수 능력**(레벨 따라 완만하게 강화). 경기 중엔 **착용 검 능력만** 쓴다.
- 거리와 능력 판정은 **서버가 검증**한다(속도 조작 치트 방지).

### 검 여러 개 (P24~P26)

- 기본 검은 모두 같은 능력치. **소지 상한 1칸 = 15강 강화 비용 × 150 × 검 수 할증**
  (약 4억 9천만, 15강 경주 약 20판) — 15강 이후 후반 콘텐츠.
- 상한 1칸을 사면 **새 검 뽑기 1회**: 등급별 차등 확률, 이미 가진 검은 제외, 확률 공개, 골드로만.
- 검은 **기본 20종**, 등급 common · rare · epic · legend (낮은 등급일수록 많음).
  **기본 능력치는 모두 같고**, 등급은 특수 능력의 세기에만 차이를 준다.
- **착용 검을 골라** 경주에 나간다.
- **도감 = 검 1종당 1칸**, 키운 최고 레벨 표시. 검마다 5·10·15·20강을 처음 달성하면
  작은 영구 업그레이드(골드 획득 %, 능력치 % 등). 검을 많이·높이 키울수록 강해진다.
  등급이 높은 검일수록 더 좋은 종류, 종류별 상한 있음. (따로 있던 소지 보너스는 삭제)
- 등급별 검 수 8·6·4·2 (일반·희귀·영웅·전설), 첫 뽑기 등급 확률 약 64·28·7·1%.
- 검이 많을수록 모든 검의 강화 비용에 (검 수)^1.1 할증.

### 경제

| 골드 획득 | 골드 소비 |
|---|---|
| 경주 (비용 × 배율 × 달린 비율 + 1~3위 보너스) | 강화 비용 |
| 로비 트레드밀 20초당 100 (여러 단계, 무료만) | 검 소지 상한 구매 |
| 시작 100 · 출석 100~1,000(7일 연속) · 15분마다 120 ※ (도감 칸 150골드는 기념 업그레이드로 대체, P35) | |

※ 출석·플레이 보상·도감·시작 골드 수치는 프로토타입 구현 때 임의로 채운 값이며
아직 승인받지 않았다. 새 경제에 맞춰 다시 맞출 대상이다.

### 수익화 (P6~P12)

- **골드는 Robux 로 직접도 간접적으로도 얻을 수 없다.** 골드 팩·게임패스 없음.
- **방지권이 유일한 유료 상품**: 확정 1개(1개당 가장 비쌈) / 확정 묶음 / 확률형(가장 저렴).
- 게임 안의 **모든 확률을 공개**한다. 방지권을 켜면 표시 확률도 바뀐다.
- 유료 확률형이 금지된 국가 유저에게는 확률형 상품을 숨기고 확정형만 보여 준다.

### 삭제된 것

1:1 배틀 · 골드 팩 · 방지권 골드 구매 · 무기 외형 변경 · 게임패스 전부 · 업적 전부 · 유료 트레드밀(취소).
업적과 게임패스는 "일단 삭제, 나중에 재설계"다.

## 2. 왜 이렇게 정했나 (판단 근거)

### 골드를 Robux 와 끊은 이유 — 로블록스 정책

로블록스 공식 정책 문서("Paid random items policy guidelines")에서 확인한 내용이다.

- **"Robux 로 살 수 있는 게임 화폐"로 하는 확률 행위도 유료 확률형 아이템**이다.
  예시 목록에 **"강화 아이템", "확률적으로 성공하는 업그레이드"** 가 그대로 있다.
- 유료 확률형이면: 사기 전에 모든 결과와 확률을 %로(합계 100%) 공개해야 하고,
  일부 국가 유저(`PolicyService` 의 `ArePaidRandomItemsRestricted`)는 아예 쓸 수 없게
  막아야 한다.
- 골드 팩을 팔면 **게임의 핵심인 강화 자체가 규제 대상**이 된다.
  골드를 끊어 두면 강화는 "돈을 쓰지 않는 확률"로 남는다.

### 강화 난이도 (0강 → 20강 기대 시도 횟수, 10강 복귀 규칙)

| 2구간 곡선 | 기대 시도 |
|---|---|
| **완만한 로그형 66% 시작 (채택, P27)** | **약 9천 4백 번** |
| 이전 지수형 초안 | 약 9만 4천 번 |

### 트레드밀이 경주를 넘지 못하는 이유

- 트레드밀은 시간당 1만 8천. 100시간 돌려도 1,800만으로 20강 경주 한 판(최대 약 10억)보다
  훨씬 적다. 그래서 자리 비움 제한을 따로 두지 않았다.

### 레벨 섞인 경주를 택한 이유

- 강화하면 "더 멀리 간다"와 "남을 방해할 수 있다"가 눈앞에서 보여 강화 욕구를 자극한다.
- 같은 서버 안에서 모이는 대로 출발하니 10초 안 매칭이 쉽다.
- 저레벨이 방해받는 문제는 트레드밀 기본 소득으로 보완하고, 신규 유저 보호는 D17 로 남겼다.

| 3 | **D6** | 1~3위 보너스 | 크기, 보너스 최소 인원(부계정 몰아주기 방지) | 최소 4명 | 경주 보상 |
| 4 | **D17** | 신규 유저 보호 | 처음 몇 판 또는 0~3강은 방해받지 않음 | 처음 10판 | 첫인상 |

| 6 | **D12** | 파편·방지권 수치 | 2구간 실패 시 파편 양, 파편 뽑기 확률, 방지권 상품 개수·가격. 조건: 확률형 3회 가격 > 확정 1개 가격 | — | 상품 출시 |

| 8 | **D24** | 추가 수익화 (방지권 외) | 실패 직후 방지권 제안, 묶음 단계 가격·첫 구매 할인, 꾸미기·기간 한정·체인 팩, 시즌 패스, 과시 연출, 개인 서버, 프리미엄, 편의 패스 (기획서 3-7 M1~M11) | 꾸미기 + 실패 직후 제안 먼저 | 수익 |

### 정해진 결정: D8 → P15 (1구간 곡선)

1구간 성공 확률을 100% → 15%, **처음엔 조금씩·갈수록 크게 떨어지는** 곡선으로 바꿨다
(100, 97, 94, 89, 84, 76, 66, 53, 37, 15).

- 9→10강(15%)이 10→11강(80%)보다 어려운 건 의도다. 1구간은 잃을 게 없어 무한히 도전할
  수 있고, 10강부터는 아래로 떨어지지 않는 바닥이 생기므로 문턱이 높아야 한다.
  5%는 도전 의욕을 꺾을 수 있어 15%로 올렸다.
- 0강 → 10강 기대 시도 약 20번.

### 정해진 결정: D10 → P14 (꽝 → 천장 포인트)

방지권 확률형 상품에서 꽝이 나오면 **천장 포인트 1점**, **3점이 쌓이면 방지권 1장**을
자동으로 준다. 가격은 나중에 정한다 (D12).

- 고른 이유: "아무것도 못 받는 결과"가 없어지고, 확정 1개보다 싼 확률형 가격 구조도
  유지된다. 꽝에서 파편을 주는 안(B)은 파편 뽑기까지 유료 확률형으로 만들어서 뺐다.
- 천장 포인트는 확률형 꽝에서만 생기고 다른 데 쓸 수 없다. 파편은 무과금 전용으로 남는다.
- 가격 조건: **확률형 3번 가격 > 확정 1개 가격.** 아니면 확정 1개가 팔리지 않는다.

### 결정 없이 이미 정해진 원칙 (참고)

- 다시 게임패스를 만들 때도 **골드·파편 획득량에 영향을 주면 안 된다.**
- 다른 유료 확률형 상품을 추가하려면 별도 검토·승인이 필요하다.

## 4. 코드 현황과 해야 할 일

**구현 진행 (2026-11-14)**: 걷어 내기, 강화 2구간 규칙, 검 여러 개(보관함·착용·소지 상한 구매·뽑기·도감 기록,
저장 스키마 v4), 추격 생존 경주와 로비·트레드밀 1단계, 방지권 상품 3종·천장 포인트·파편 뽑기까지 코드에 넣었다
(테스트 154개 통과, Rojo 빌드 확인, Studio 실동작 미확인).
수치가 미정인 것(상품 ID·개수·확률, 순위 보너스, 특수 능력, 트레드밀 2단계 이상, 검 15종)은 비워 두었고,
비어 있는 상품은 상점에 보이지 않는다. 아래 표는 처음 계획이다.

| 걷어 낼 것 | 새로 만들 것 |
|---|---|
| 1:1 배틀 전체 | **추격 생존 경주** (가장 큰 작업: 매칭, 코스 생성, 추격자, 서버 거리 검증, 특수 능력, 관전) |
| 골드 팩 · 게임패스 | 강화 2구간 규칙 |
| 방지권 골드 구매 | 파편 뽑기 |
| 업적 | 방지권 상품 3종 + 정책 대응 (확률 공개, 제한 국가 처리, 결제 재시도 시 재추첨 금지) |
| | 방지권 ON 시 표시 확률 변경 |
| | **검 여러 개**: 소지 상한 구매, 새 검 뽑기(확률 공개), 착용 선택, 도감 기념 업그레이드, 비용 할증 |
| | 로비 트레드밀 (여러 단계) |

저장된 플레이어 데이터는 기획에서 빠진 항목이라도 지우지 않는다(스키마 규칙).

| Roblox Studio 실동작 | 화면·저장·채팅 명령어는 **아직 Studio 에서 돌려 보지 않았다** (개발 환경 제약) |
| "꽝 결과 금지" 규정 | 로블록스 개발자 포럼 공지에 "돈만 내고 아무것도 못 받는 결과는 안 된다"는 요건이 있다고 검색에 나왔으나, **원문은 접속이 막혀 확인하지 못했다.** 공식 정책 문서에는 그 조항이 없었다. 안전하게 꽝 대신 포인트를 주는 쪽으로 정했다 (P14) |
| 한국 확률형 아이템 법 | 2024년 3월부터 확률 공개가 법적 의무. **개인 로블록스 개발자에게 적용 범위는 확정하지 못했다.** 로블록스 정책을 지키면 핵심(확률 공개)은 겹친다 |
| 아트·사운드 | 무기 외형, 효과음, 로비·코스 미술이 없다. 코드로 블록 배치까지만 가능 |
