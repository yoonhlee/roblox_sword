## 1. 가장 빠른 방법

**필요한 것: Roblox Studio 하나뿐이다.** 터미널도, Rojo 도, Wally 도 필요 없다.

### 1-1. Roblox Studio 설치

https://create.roblox.com/ 에 로블록스 계정으로 로그인하고 **Start Creating** 을
누르면 Studio 설치 파일을 받을 수 있다. (Windows / macOS 만 가능하다.
리눅스나 크롬북에서는 Studio 가 돌아가지 않는다.)

### 1-2. 플레이스 파일 받기

저장소에 **`ForgeFever.rbxlx`** 파일이 들어 있다. 이 안에 게임 전체가 담겨 있다.

GitHub 웹에서 받는 법:

1. 저장소에서 최신 개발 브랜치(`claude/...` 로 시작하는 것 중 가장 최근 것)를 연다
2. `ForgeFever.rbxlx` 를 클릭한다
3. 오른쪽 위 **Download raw file** (아래 화살표 아이콘) 을 누른다

### 1-3. 열고 실행하기

1. 받은 `ForgeFever.rbxlx` 를 **더블클릭**한다 → Roblox Studio 가 열린다
   (안 열리면 Studio 를 먼저 켜고 `File > Open from File` 로 연다)
2. 상단 **Home** 탭의 **Play** 버튼(▶)을 누른다
3. 해 질 녘 대장간 마을(불씨 광장)에 서고, 화면에 대장간 창(큰 레벨 숫자와 강화 버튼)이 열려 있으면 성공이다
   (화면이 가로로 고정된다. 처음 접속하면 대장간 창이 열린 채 시작한다)

> **Play 를 눌렀는데 아무것도 안 보인다면** 화면 아래쪽 **Output** 창을 봐라.
> (안 보이면 상단 `View` 탭 → `Output`) 빨간 글씨가 있으면 그 내용을 알려 줘.

**정상일 때 Output 에 찍히는 것:**

```
[WorldService] 로비 준비 완료 (트레드밀 발판 4개)
[DataService] 스토어 "ForgeFever_DEV" 사용
[Bootstrap] 서비스 15개 시작 완료
[ChatCommandService] 명령어 4개 등록
```

강화 버튼을 누를 때마다 이런 줄이 추가된다:

```
[Economy] 12345 gold sink -200 (enhance_cost) → 0
[Enhance] 12345 +0 → success (비용 200)
```

> **테스트용 골드 넣기**: 골드는 경주와 트레드밀로 벌 수 있지만, 높은 레벨을 빨리 시험하려면 관리자 명령이 편하다.
> `src/shared/Config/Game.luau` 의 `ADMIN_USER_IDS = {}` 안에 본인 UserId(로블록스 프로필 주소에 있는 숫자)를
> 넣으면 채팅에 `/관리 골드 <내 닉네임> 1000000000` 을 칠 수 있다. 방지권은 `/관리 방지권 <닉네임> 10`,
> 레벨은 `/관리 레벨 <닉네임> 15`. Studio 안에서 바로 고쳐도 되고(ReplicatedStorage > Shared > Config > Game),
> 저장소 파일을 고쳤다면 플레이스 파일을 다시 만들어야 한다. 혼자 **Play** 로 테스트할 때만 된다
> (2인 Local Server 테스트는 가짜 번호로 들어와서 관리자로 인식되지 않는다).

## 2. 혼자서 확인할 것

Play 상태에서 하나씩 해 보면 된다. **화면과 세계는 전부 새로 만들었고 Studio 에서 한 번도 돌려 보지 못했다.**
겹치거나 잘리거나 이상하게 보이는 곳이 있으면 스크린샷을 보내 줘 (아래 "찍어 줄 장면").

### 대장간 창 (강화)

| 확인할 것 | 방법 | 기대 결과 |
| --- | --- | --- |
| 첫 화면 | Play 직후 | 대장간 창이 열려 있다. 왼쪽에 검 이름·돌아가는 3D 검·큰 레벨 숫자, 오른쪽에 확률·방지권·비용·큰 강화 버튼. 강화 버튼 위에 노란 말풍선 안내 |
| 위쪽 재화 칩 | 화면 왼쪽 위 | 금색 동그라미(골드)·하늘색 마름모(파편)·초록 방패(방지권)와 숫자. 로블록스 기본 버튼과 겹치지 않는다 |
| 강화 | 큰 강화 버튼 | 망치질(0~9강 0.5초) 뒤 결과. 성공이면 레벨 숫자가 튀어 오르고 번쩍인다. 아래 피드 칸에 모루 영감 대사 |
| 높은 레벨 연출 | `/관리 레벨 <닉네임> 15` 후 강화 | 망치질이 3번(약 2초), 주변이 어두워진다. 화면을 누르면 바로 결과로 넘어간다 |
| 레벨 색 | 레벨을 바꿔 본다 | +0~4 회색 → +5~9 붉게 → +10~14 주황 → +15~19 노랗게 → +20 흰색. 3D 검 테두리도 같은 색 |
| 확률 막대 | 오른쪽 가운데 | 주황(성공)·회색(유지)·빨강(실패) 막대와 "성공 · 유지 · 실패 %". 0~9강은 "1구간 · 실패 없음" |
| 방지권 | `/관리 방지권 <닉네임> 5`, 10강 이상에서 "방지권" 버튼 | 버튼이 주황으로 켜지고 빨간 칸이 사라지며 회색이 늘어난다(실패 0%) |
| 비용 | 비용 줄 | "비용 N 골드 · 지금 M번 가능". 모자라면 빨간 글씨 + 강화 버튼 회색 |
| 확률표 | "확률표" 버튼 | 0~20강 표, "1구간"·"2구간" 구분 줄, 지금 레벨 줄이 주황. 오른쪽 위 빨간 X 로 닫힌다. 바깥을 눌러도 닫힌다 |
| 검 · 기록 · 상점 | 강화 버튼 왼쪽 네모 버튼 3개 | 각 창이 열린다. 창은 한 번에 하나만 |
| 대장간 닫기 | 대장간 창 오른쪽 위 빨간 X | 로비 화면으로. 이동 조이스틱이 다시 보인다(휴대폰 화면) |
| 이름 짓기 | 대장간 창의 검 이름을 누른다 | 입력 창 → 이름이 바뀐다 |

### 창 (검 · 기록 · 상점)

| 확인할 것 | 방법 | 기대 결과 |
| --- | --- | --- |
| 검 보관함 | "검" | 왼쪽에 검 카드(등급 색 띠, 레벨 색 숫자, 착용 중 표시), 오른쪽에 새 검 뽑기(가격, 등급별·검별 확률 막대, 합계 100%) |
| 뽑기 | 골드를 넣고 뽑기 버튼 두 번 | 첫 번째에 빨간 확인 문구로 바뀌고, 두 번째에 뽑는다. "새 검!" 카드가 등급 색으로 튀어나온다 |
| 착용 | 다른 검 카드를 누른다 | 착용이 바뀌고 대장간 창의 3D 검·레벨, 손에 든 검이 그 검으로 바뀐다 |
| 도감 | "기록" → 도감 | 20칸 격자. 가진 검: 이름·최고 +N·기념 점 4개. 아직 없는 검: "?", 나머지 15칸: "준비 중" |
| 랭킹·설정 | "기록" → 랭킹 / 설정 | 랭킹은 Studio 에서 비어 있는 게 정상. 설정에서 소리·언어(영어로 바꾸면 화면·세계 글자 전부 영어) |
| 상점 | "상점" | "아직 상품이 등록되지 않았다" + 확률 공개 약속 문구 (상품이 미정이라 정상) |

### 불씨 광장 (로비)

| 확인할 것 | 방법 | 기대 결과 |
| --- | --- | --- |
| 광장 | 대장간 창을 닫는다 | 해 질 녘 하늘, 돌바닥·돌담·횃불, 가운데 대장간 건물(화덕 불빛·굴뚝 연기), 북쪽 쇳물 관문, 서쪽 러닝머신 4대, 동쪽 명예의 벽 |

| 경주 버튼 | 화면 오른쪽 위 "경주" | 원에 서지 않아도 대기열에 들어간다. 다시 누르면 취소 |

### 찍어 줄 장면 (스크린샷)

Studio 상단 **Test** 탭 → **Device**(기기 에뮬레이터)에서 기기를 고르고 Play 한다. 아래를 찍어서 보내 주면 겹침·잘림을 고친다.
한국어로 한 번, 기록 → 설정에서 영어로 바꿔 한 번 찍어 주면 더 좋다.

1. 휴대폰 가로(작은 기기, 예: iPhone SE) — 첫 화면(대장간 창)
2. 같은 기기 — 대장간 창을 닫은 로비 화면 (왼쪽 메뉴·오른쪽 위 경주 버튼·위쪽 칩이 보이게)
3. 같은 기기 — 확률표 창 / 검 보관함 창 / 기록 → 도감
4. 같은 기기 — 러닝머신 위에 선 모습(아래 20초 막대)과 관문 원에 선 모습(전광판·고리)
5. 같은 기기 — 경주 중 화면, 탈락 후 결과 카드
6. 노치가 있는 휴대폰 가로(예: iPhone 14) — 1·2번 화면
7. 태블릿(예: iPad) — 1·2번 화면
8. PC 창 — 1·2번 화면, 광장을 멀리서 본 모습(대장간·관문·러닝머신이 한 화면에)

Output 에는 경주마다 `[Funnel] ... race_start`, `[Economy] ... gold source N (race_reward)`, `[Funnel] ... race_eliminated` 가 찍힌다.

### 상점

지금은 상품 ID·개수·확률이 정해지지 않아 **"아직 상품이 등록되지 않았다"만 보이는 게 정상**이다.
확률형 표시를 미리 보고 싶으면 Studio 에서 ReplicatedStorage > Shared > Config > Products 를 열어 시험 값을 넣어 본다
(저장소 파일은 고치지 말 것 — 확정된 수치가 아니다):

- `SHARD_DRAW` 의 `outcomes = {}` 를 `outcomes = { { tickets = 1, weight = 1 }, { tickets = 0, weight = 3 } }` 로 바꾸면
  상점에 "파편 뽑기"와 확률(25% / 75%, 합계 100%)이 보인다. 파편은 2구간에서 실패하면 생긴다.
- Robux 상품은 게임을 올리고 개발자 상품을 만들어 ID 를 넣어야 보인다(아래 6절).

**없어진 것**(보이면 안 된다): 배틀 버튼, 판매 버튼, 업적 탭, 배틀 레이팅 랭킹, 파편 → 방지권 교환.

**랭킹은 비어 있는 게 정상이다.** 랭킹은 실제로 게임을 공개해서 DataStore 가
동작할 때부터 쌓인다 (아래 4번 참고).

## 3. 2명으로 확인하기

1. 상단 **Test** 탭 → **Clients and Servers** 에서 **Players = 2**, 모드 **Local Server**
2. **Start** 를 누른다 → 창이 3개 열린다 (서버 1 + 플레이어 2)

확인할 것:

- 한쪽에서 강화해도 다른 쪽 골드·레벨은 변하지 않는다
- 한쪽이 15강 이상을 성공하면 다른 쪽 채팅창에도 알림이 뜬다
- 둘이 10초 안에 "경주" 버튼을 누르거나 관문 바닥 원에 함께 서면 **같은 판**에 선다(대기 인원 2명, 전광판 2/20)
- 한쪽이 러닝머신을 달리면 다른 쪽 화면에서도 벨트·풀무가 움직이고 20초마다 "+100" 이 보인다
- 경주 진행 막대에 상대 점이 보인다
- 캐릭터끼리 서로 통과한다(부딪치지 않는다)
- 먼저 잡힌 쪽 화면에 "관전 중: 상대 이름"이 뜨고 카메라가 상대를 따라간다. 상대가 잡히면 순위표가 뜬다
- 순위: 더 오래 버틴 쪽이 1위
- 한쪽이 경주 중일 때 다른 쪽이 매칭을 누르면 **다른 코스**(옆자리)에서 따로 출발한다
- 경주 중인 쪽 창을 닫아도(접속 종료) 서버 Output 에 오류가 없다

2인 Local Server 에서는 관리자 명령을 쓸 수 없다(가짜 번호로 접속한다). 레벨이 다른 경주를 보려면 한쪽에서 강화를 몇 번 해 둔다.

끝낼 때는 **Test 탭 → Cleanup** 을 누른다.

## 4. 데이터 저장을 진짜로 테스트하기

**1번 방법(파일 더블클릭)으로 연 게임은 데이터가 저장되지 않는다.** Studio 를
끄면 골드와 레벨이 초기화된다. 정상이다 — 로블록스는 "아직 공개되지 않은
플레이스"에 데이터 저장을 허용하지 않는다.

진짜 저장을 확인하려면:

1. Studio 에서 **File → Publish to Roblox As...** 로 게임을 한 번 올린다
   (비공개로 올려도 된다. 공개할 필요 없다)
2. Studio 상단 **Home → Game Settings → Security** 로 간다
3. **Enable Studio Access to API Services** 를 **켠다**
4. **Save** 를 누른다
5. 다시 Play 해서 골드를 쓰고, Studio 를 완전히 껐다가 다시 열어 Play 한다
6. 골드와 레벨이 그대로 남아 있으면 성공이다

> Studio 에서 테스트하는 데이터는 `ForgeFever_DEV` 라는 별도 저장소에 들어간다.
> 실제 공개된 게임은 `ForgeFever_PROD` 를 쓴다. **둘은 절대 섞이지 않는다.**
> 그래서 Studio 에서 아무리 골드를 넣고 테스트해도 실제 유저 데이터는 안전하다.

### 서버 강제 종료 후에도 데이터가 남는지

ProfileStore 가 서버 종료 시 모든 데이터 저장이 끝날 때까지 기다리도록 되어 있다.
Test 탭에서 **Local Server** 로 실행한 뒤 **Cleanup** 으로 강제 종료하고,
다시 Play 해서 데이터가 남아 있는지 확인하면 된다.

## 5. 코드를 고치면서 개발하려면

1번 방법의 플레이스 파일은 **특정 시점의 사진** 이다. 코드를 고쳐도 그 파일은
바뀌지 않는다. 계속 개발하려면 파일과 Studio 를 실시간으로 연결하는
**Rojo** 를 쓴다.

### 5-1. 툴 설치

터미널(Windows 는 PowerShell, Mac 은 터미널)에서 [Rokit](https://github.com/rojo-rbx/rokit)
을 설치한 뒤, 저장소 폴더에서:

```bash
rokit install
```

`rokit.toml` 에 적힌 rojo / selene / stylua / lune 가 한 번에 설치된다.

> 버전 오류가 나면 버전 없이 다시 고정하면 된다:
> `rokit add rojo-rbx/rojo` `rokit add JohnnyMorganz/StyLua` 등

### 5-2. Studio 플러그인 설치

```bash
rojo plugin install
```

### 5-3. 연결

```bash
rojo serve
```

Studio 에서 새 Baseplate 를 만들고, **Plugins** 탭의 **Rojo** 창에서
**Connect** 를 누른다. (기본 주소 `localhost:34872`)

연결되면 `src/` 의 파일들이 Studio 안으로 들어온다. 이제 파일을 저장할 때마다
Studio 에 즉시 반영된다.

> **Studio 안에서 스크립트를 직접 고치지 마라.** 다음 동기화 때 덮어써진다.
> 코드는 항상 파일에서 고친다.

### 5-4. 다시 플레이스 파일로 만들기

```bash
rojo build -o ForgeFever.rbxlx
```

### 5-5. 테스트와 검사

```bash
lune run tests/run                # 로직 테스트 230개
lune run tools/simulate_economy   # 강화 시뮬레이션
stylua src tests tools            # 코드 정렬
selene src tests tools            # 코드 검사
```

## 6. 게임을 공개하려면

`README.md` 의 **출시 전 체크리스트** 를 따르면 된다. 핵심만 적으면:

1. **File → Publish to Roblox** 로 게임을 올린다
2. **Game Settings → Security → Enable Studio Access to API Services** 를 켠다
3. `src/shared/Config/Game.luau` 의 `ADMIN_USER_IDS` 에 본인 UserId 를 넣는다
   (UserId 는 자기 로블록스 프로필 주소의 숫자다)
4. 방지권 개발자 상품 3개(확정 1개 / 확정 묶음 / 확률형)를 만들고 `src/shared/Config/Products.luau` 에 ID 를 넣는다
   (묶음 개수와 확률형 확률은 아직 미정 — 같은 파일에 함께 채운다)
   - **ID 를 안 넣어도 게임은 정상 동작한다.** 상점이 비어 있을 뿐이다
   - 가격은 대시보드에서 정한다. **확률형 3번 가격이 확정 1개 가격보다 비싸야 한다**
   - **확률형 상품은 게임 소개 페이지의 Store 탭에 올리지 않는다** (확률형이 금지된 나라의 유저가 살 수 있게 된다)
5. 아이콘·썸네일·설명을 등록한다 (전부 오리지널 에셋으로)
6. 친구 5명 이상과 비공개 테스트를 한다

## 7. 문제가 생겼을 때

먼저 **Output 창**(View 탭 → Output)을 확인한다. 아래는 나올 수 있는 메시지와 뜻이다.

### `ProfileStore 모듈을 찾을 수 없습니다`

Rojo 동기화가 덜 됐다. `src/server/vendor/ProfileStore.luau` 가 Studio 의
`ServerScriptService > Server > vendor` 아래에 들어와 있는지 확인한다.

### `TextChatService 가 아닌 레거시 채팅이 켜져 있어...`

채팅 명령어가 등록되지 않았다는 뜻이다. **Game Settings → Communication** 에서
채팅을 최신 방식(TextChatService)으로 바꾼다. 버튼은 전부 정상 동작하므로
급하지 않으면 넘어가도 된다.

### `관리자 UserId 가 비어 있어 관리자 명령을 등록하지 않았습니다`

정상이다. `Config/Game.luau` 의 `ADMIN_USER_IDS` 를 채우면 `/관리` 명령이 켜진다.
비워 두면 아무도 관리자 명령을 쓸 수 없다 — 안전한 기본값이다.

### `순위 저장소를 열지 못했습니다` / 랭킹이 비어 있다

DataStore 접근이 아직 허용되지 않았다. 위 4번을 따른다.
게임 진행에는 아무 영향이 없다.

### 데이터가 저장되지 않는다

위 4번을 따랐는지 확인한다. 공개되지 않은 플레이스에서는 저장이 안 되는 게 정상이다.

### 그 외

Output 창의 빨간 글씨를 **그대로 복사해서** 알려 주면 된다. 어느 줄에서 났는지까지
찍히므로 대부분 바로 고칠 수 있다.
