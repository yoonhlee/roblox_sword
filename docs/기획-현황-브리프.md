# 강화의 대장간 — 기획 현황 브리프

> 작성일 2026-11-14 · 대상: 이 프로젝트를 처음 보는 동료
> 상세 기준 문서는 `docs/기획서.md`. 이 문서는 **판단에 필요한 것만** 추린 요약이다.

---

## 30초 요약

- **무엇**: 로블록스 모바일 게임. 검을 골드로 강화하고, 그 검을 들고 **추격 생존
  경주**를 달려 골드를 번다. 결과는 오리지널 NPC "모루 영감"이 한 줄씩 읊어 준다.
- **어디까지 왔나**: 처음 지시서 기준 프로토타입(강화 + 1:1 배틀)은 **코드로 완성**돼 있다.
  그 뒤 기획을 크게 바꿨고(제안 13건 승인), **새 기획은 아직 코드에 반영하지 않았다.**
- **바뀐 핵심 세 가지**
  1. 게임 목표: 1:1 배틀 → **추격 생존 경주** (달린 거리만큼 골드)
  2. 강화: **2구간** — 1~10강 실패 없음, 11~20강 실패하면 10강으로 복귀
  3. 수익화: 골드를 Robux 와 완전히 분리, **방지권이 유일한 유료 상품**
- **지금 필요한 것**: 결정 8건 (아래 3절). 이 중 **D10·D8·D5** 를 먼저 정하면
  구현 순서를 잡을 수 있다.

## 1. 게임 구조 (승인된 기획)

```
   골드 ──→ 강화 ──→ 더 강한 검 ──→ 추격 생존 경주 ──→ 달린 거리만큼 골드
             │                       (검 종류·강화 레벨이 능력으로 작용)
             ├─ 1구간 1~10강: 실패 없음
             ├─ 2구간 11~20강: 실패하면 10강 복귀 → 파편 획득
             └─ 판매: 쓴 비용 일부 페이백

   파편 50개 ──→ 방지권 뽑기          방지권 ──→ 2구간 실패를 막아 줌
   Robux ──→ 방지권 상품 (유일한 유료 상품)
```

### 강화 (P1·P2·P5)

| | 1구간 (1~10강) | 2구간 (11~20강) |
|---|---|---|
| 성공 | 100% → 5% 점진 하강 | 80% → 2% 지수 하강 |
| 실패 | 0% | 5% → 20% 점진 상승. **실패하면 10강으로 복귀** |
| 유지 | 100 − 성공 | 100 − (성공 + 실패) |
| 판매가 | ((10 + 레벨) / 10) × 레벨별 강화 비용 합 | **미정 (D3)** |

- 판매 목적은 **페이백**이지 이익이 아니다. 판매 후 **10초 쿨다운**.
- 강화 비용표는 **미정 (D9)**.

### 추격 생존 경주 (P3)

- 다 같이 출발 → 뒤에서 무너지는 바닥이 쫓아옴(점점 빨라짐) → 잡히면 탈락.
  마지막 1명이 남거나 2분이 지나면 종료.
- 수익: **버틴 거리 × 단가 + 생존 보너스.** 탈락해도 달린 만큼은 받는다.
- 경쟁: 밀치기·감속 같은 **검 능력으로 남을 추격자 쪽으로 떨어뜨리는 것**이 핵심.
- 코스는 코드로 자동 생성(매 판 다름).
- 검 종류 → 고유 능력, 강화 레벨 → 속도(상한 있음)·능력 위력. **능력 목록은 초안.**
- 거리와 능력 판정은 **서버가 검증**한다(속도 조작 치트 방지).

### 경제

| 골드 획득 | 골드 소비 |
|---|---|
| 경주 (수치 미정, D6) | **강화 비용뿐** |
| 무기 판매 | |
| 시작 100 · 출석 100~1,000(7일 연속) · 15분마다 120 · 도감 칸 150 ※ | |

※ 출석·플레이 보상·도감·시작 골드 수치는 프로토타입 구현 때 임의로 채운 값이며
아직 승인받지 않았다. 경주 보상(D6)과 함께 다시 맞출 대상이다.

### 수익화 (P6~P12)

- **골드는 Robux 로 직접도 간접적으로도 얻을 수 없다.** 골드 팩·게임패스 없음.
- **방지권이 유일한 유료 상품**: 확정 1개(1개당 가장 비쌈) / 확정 묶음 / 확률형(가장 저렴).
- 게임 안의 **모든 확률을 공개**한다. 방지권을 켜면 표시 확률도 바뀐다.
- 유료 확률형이 금지된 국가 유저에게는 확률형 상품을 숨기고 확정형만 보여 준다.

### 삭제된 것

1:1 배틀 · 골드 팩 · 방지권 골드 구매 · 무기 외형 변경 · 게임패스 전부 · 업적 전부.
업적과 게임패스는 "일단 삭제, 나중에 재설계"다.

## 2. 왜 이렇게 정했나 (판단 근거)

### 골드를 Robux 와 끊은 이유 — 로블록스 정책

로블록스 공식 정책 문서("Paid random items policy guidelines")에서 확인한 내용이다.

- **"Robux 로 살 수 있는 게임 화폐"로 하는 확률 행위도 유료 확률형 아이템**이다.
  예시 목록에 **"강화 아이템", "확률적으로 성공하는 업그레이드"** 가 그대로 있다.
- 유료 확률형이면: 사기 전에 모든 결과와 확률을 %로(합계 100%) 공개해야 하고,
  일부 국가 유저(`PolicyService` 의 `ArePaidRandomItemsRestricted`)는 아예 쓸 수 없게
  막아야 한다.
- 골드 팩을 팔면 **게임의 핵심인 강화 자체가 규제 대상**이 된다.
  골드를 끊어 두면 강화는 "돈을 쓰지 않는 확률"로 남는다.

### 강화 난이도 (2구간 초안 곡선 기준, 0강 → 20강 기대 시도 횟수)

| 실패 규칙 | 기대 시도 |
|---|---|
| **10강 복귀 (채택)** | **약 10만 2천 번** |
| 1단계 하락 | 약 1만 9천 번 |
| 0강 초기화 | 약 51만 번 |
| (참고) 프로토타입 현재 확률표 | 약 3만 3천 번 |

며칠이 걸리는지는 비용표(D9)와 경주 수입(D6)이 정해져야 나온다.

### 판매 공식의 남은 위험

- 1~4강은 성공률이 거의 100%라 판매가가 평균 지출보다 약간 크다
  (1강 = 100골드 가정 시 한 번에 +10 ~ +105). 손으로 할 이유는 없는 금액이라
  공식을 유지하고, **10초 쿨다운으로 매크로를 막기로** 했다.
- 단, 매크로가 4강까지 올려 파는 경우 10초 쿨다운에서도 **시간당 약 3만 8천 골드**
  (같은 가정). 경주가 판당 1,000골드면 시간당 약 2만이므로 넘어설 수 있다.
  → **비용표(D9)를 정할 때 반드시 비교**하고, 넘으면 쿨다운을 늘린다(60초면 약 6천).

## 3. 결정이 필요한 것

우선순위 순. "막는 것"은 이 결정이 없으면 진행할 수 없는 작업이다.

| 우선 | # | 결정할 것 | 선택지 | Claude 추천 | 막는 것 |
|---|---|---|---|---|---|
| 1 | **D10** | 방지권 확률형 상품의 "꽝" 대신 줄 것 | **A** 꽝 없이 무조건 1~3개 / **B** 꽝 → 파편 / **C** 꽝 → Robux 전용 천장 포인트 (예: 5포인트 = 방지권 1개) | **C** (대안 A) | 상품 구성, D12 |
| 2 | **D8** | 강화 곡선 역전 해소 | 9→10강(5%)이 10→11강(80%)보다 어렵다. 1구간 하한을 올리기(예: 30%) / 2구간 시작을 낮추기 | 1구간 하한 올리기 | D9 |
| 3 | **D5** | 경주 고레벨 독주 방지 | 능력치 상한 / 레벨대별 매칭 / 꼴찌 보정 (조합 가능) | 아직 논의 전 | 경주 설계 |
| 4 | **D6** | 경주 보상 수치 | 거리 단가, 생존 보너스, 하루 상한 | — | D9, D3 |
| 5 | **D9** | 강화 비용표 | 시뮬레이션으로 맞춤. **매크로 판매 시간당 수익 < 경주 시간당 수익** 확인 필수 | — | D3 |
| 6 | **D3** | 2구간 판매가 | 경주 수입이 정해진 뒤 | — | — |
| 7 | **D12** | 파편·방지권 수치 | 2구간 실패 시 파편 양, 파편 뽑기 확률, 방지권 상품 개수·가격 | — | 상품 출시 |
| 8 | **D7** | 배틀이 빠진 자리 | 배틀 레이팅 랭킹을 경주 기록(최장 거리 등)으로 대체할지 | 경주 기록으로 대체 | 랭킹 |

### D10 상세 — 왜 "꽝 → 파편"(B)이 문제인가

확률형 상품에서 파편이 나오면 파편이 "Robux 로 얻을 수 있는 재화"가 되고, 그 파편으로
하는 방지권 뽑기가 정책 문서의 예시 **"Robux 로 뽑기권을 사서 뽑기에 쓰는 것"** 에
해당한다. 금지는 아니지만:

1. 제한 국가 유저는 파편 뽑기를 못 쓴다 → 그 나라 무과금 유저의 방지권 경로가 사라짐
2. 무료로 모은 파편과 돈으로 받은 파편이 섞인 경우를 정책 문서가 다루지 않는다

| | 장점 | 단점 |
|---|---|---|
| A 꽝 없음 | 가장 단순. 파편은 순수 무과금 재화 | 최소 1개 보장이라 확정 1개보다 싸게 못 판다 → "저렴한 확률형" 구조가 깨짐 |
| B 꽝 → 파편 | 원래 안 그대로 | 위 1·2번 |
| C 천장 포인트 | 가격 구조 유지 + 파편은 무과금 재화로 남음 + 꽝이 쌓이면 확정 보상 | 재화가 하나 늘어남 |

### 결정 없이 이미 정해진 원칙 (참고)

- 다시 게임패스를 만들 때도 **골드·파편 획득량에 영향을 주면 안 된다.**
- 다른 유료 확률형 상품을 추가하려면 별도 검토·승인이 필요하다.

## 4. 코드 현황과 해야 할 일

**지금 코드 = 처음 지시서 기준 프로토타입** (Luau 46개 파일, 순수 로직 테스트 73개 통과,
Rojo 빌드 확인). 새 기획 구현은 결정이 정리된 뒤 시작한다.

| 걷어 낼 것 | 새로 만들 것 |
|---|---|
| 1:1 배틀 전체 | **추격 생존 경주** (가장 큰 작업: 코스 생성, 추격자, 서버 거리 검증, 능력) |
| 골드 팩 · 게임패스 | 강화 2구간 규칙 |
| 방지권 골드 구매 | 파편 뽑기 |
| 업적 | 방지권 상품 3종 + 정책 대응 (확률 공개, 제한 국가 처리, 결제 재시도 시 재추첨 금지) |
| | 방지권 ON 시 표시 확률 변경 |
| | **무기 교체** — 없으면 도감 20칸 중 16칸을 채울 수 없다 |

저장된 플레이어 데이터는 기획에서 빠진 항목이라도 지우지 않는다(스키마 규칙).

## 5. 확인되지 않은 것 · 리스크

| 항목 | 상태 |
|---|---|
| Roblox Studio 실동작 | 화면·저장·채팅 명령어는 **아직 Studio 에서 돌려 보지 않았다** (개발 환경 제약) |
| "꽝 결과 금지" 규정 | 로블록스 개발자 포럼 공지에 "돈만 내고 아무것도 못 받는 결과는 안 된다"는 요건이 있다고 검색에 나왔으나, **원문은 접속이 막혀 확인하지 못했다.** 공식 정책 문서에는 그 조항이 없었다. 안전하게 꽝 없는 쪽으로 기획했다 |
| 한국 확률형 아이템 법 | 2024년 3월부터 확률 공개가 법적 의무. **개인 로블록스 개발자에게 적용 범위는 확정하지 못했다.** 로블록스 정책을 지키면 핵심(확률 공개)은 겹친다 |
| 아트·사운드 | 무기 외형, 효과음, 로비·코스 미술이 없다. 코드로 블록 배치까지만 가능 |
